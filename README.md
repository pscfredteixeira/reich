# Círculo Reich — revisão interativa

Aplicativo complementar para estudar *Psicologia de Massas do Fascismo*, de Wilhelm Reich, depois de ler cada seção no seu exemplar físico.

## Como usar

Abra o aplicativo e toque em **Começar meus estudos**. Escolha um dos 13 capítulos e use as explicações, perguntas para reflexão, quizzes e flashcards. Não precisa cadastrar senha ou importar o EPUB.

## Recursos

- Leituras comentadas para os 13 capítulos, claramente distintas do texto de Reich.
- **26 quizzes** com respostas comentadas.
- **39 flashcards** com conceitos importantes.
- Perguntas de debate e campo para suas interpretações.
- Anotações e progresso armazenados no próprio navegador; exportação de backup.
- Interface responsiva para celular e desktop.
- Se desejar, leitor EPUB opcional, sem envio do arquivo a servidores.

O material didático não substitui o texto original do livro. O texto da edição não é reproduzido na versão de estudos.

## Publicação e privacidade

**Aviso:** o livro integral foi adicionado anteriormente à branch `conteudo-privado`. Não publique essa branch; se o repositório estiver público, o conteúdo poderá ser acessado por outras pessoas. Configure o repositório como privado para proteger essa cópia. O aplicativo de revisão da branch `main` não precisa do pacote de livro criptografado ou de senha.

O aplicativo está no repositório, mas a disponibilidade do endereço GitHub Pages depende da configuração de publicação da sua conta. Não afirmamos que o endereço público esteja funcionando sem verificar.
